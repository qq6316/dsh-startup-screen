# dsh-startup-screen

DeepSeek Harness 的启动界面与启动动画插件（泰坦陨落 2 · BT-7274 版）。

黑幕军徽 → 过曝洗白 → 军用「技术档案」底板 → 五步交互式铁驭链接 → 协议三揭幕。

---

## 功能

**开机序列**　冷启动时播一段完整的开机动画，六幕连贯：军徽番号 → 过曝洗白 →
暗色军用底板 → 五步铁驭链接 → 协议三揭幕。中央一圈环形准星缓慢自转，缺口留在
正下方，不会挡住底部文字。

**可交互，不是播片**　第一、二步要你点按钮或按 Enter 才会继续（可以关掉）。
右上角有跳过按钮，Esc 也能跳。

**中文主字 + 英文等宽副标题**　英文副标题逐字打出来，像泰坦在接收上行数据。

**BT 原声播报**　每一步由低沉男声念英文状态行，终幕念 BT 的原话——协议三：
保护铁驭。**已内置 5 句 BT 原声**（Bert-VITS2 训练的 BT-7274 AI 语音，取自
DBM-VPBT7274 语音包），其余槽位与缺素材时自动回落系统 TTS 合成男声，不影响
启动。浏览器要求先有一次点击才准出声，所以点过按钮之后才会听到声音。

**自检流水**　第四幕右上角逐项打出 REACTOR / SENSORS / WEAPONS SYSTEMS …
ONLINE，六项自检逐一点亮才继续。

**语音没播完不会推进**　每一步停留多久由实际播报时长决定。你点得快也不会把
语音掐断。

**三十三项设置**　铁驭名称、泰坦编号、授权等级、配色、速度、音色、语速、
开口留白、每处文案……都能在设置页实时改，改完立即生效。

## 安装

```bash
dsh plugin --profile web add ./dsh-startup-screen-2.1.0.tgz
```

Windows 上也可以解压 release 压缩包后**双击「安装.cmd」**，脚本会自动完成同样的操作。

**装完重启 dsh web**（关掉启动器窗口再重新双击）。重启后刷新页面就能看到启动动画，
设置页里会多出一项「启动动画」。

### 环境要求

| 项 | 要求 |
|---|---|
| 平台 | DSH **web** profile（桌面端见 DESKTOP.md） |
| Node | **>= 20** |
| 依赖 | 无（不需要 `npm install`） |

### 卸载

```bash
dsh plugin --profile web remove dsh-startup-screen
```

## 设置选项

装好后进入 **DSH 设置页 →「启动动画」**。

### 播放

| 选项 | 默认 | 作用 |
|---|---|---|
| 启用 | 开 | 总开关，关掉就完全不播 |
| 显示模式 | 每次会话 | `每次会话` 一个浏览器会话播一次 / `总是` 每次刷新都播 / `每天` 一天一次 |
| 主题 | 深色 | `深色` 军用 HUD 底板（默认）/ `浅色` 暖白档案底板 |
| 速度 | 1× | 整段动画的快慢，0.35 – 3 倍 |
| 要求确认 | 开 | 第 1、2 步是否等你点按钮才继续 |
| 允许跳过 | 开 | 是否显示右上角跳过按钮、是否响应 Esc |

### 身份资料

| 选项 | 默认 | 作用 |
|---|---|---|
| 铁驭名称 | `JACK COOPER` | 终幕「保护 xxx · PROTECT THE PILOT」里的名字 |
| 泰坦编号 | `BT-7274` | 第二步身份卡上的编号，字母数字与连字符 |
| 授权等级 | `PILOT` | 第二步身份卡上的授权等级 |

### 语音

| 选项 | 默认 | 作用 |
|---|---|---|
| 语音播报 | 开 | 是否念台词（BT 风格男声） |
| 语音来源 | BT 真声素材 | `BT 真声素材` 用 lib/assets 里的录音 / `系统 TTS 男声` 用浏览器合成；缺素材自动回落 TTS |
| 播报语言 | 英语 | `英语（BT 播报）` / `中文` / `中英各念一遍` |
| 音色 | 自动 | 留空 = 自动挑神经网络男声（中文播报挑女声） |
| 语速 | 0.88 | 越慢越有军用播报感 |
| 音调 | 0.8 | 调低更沉稳，像泰坦在说话 |
| 音量 | 0.9 | 台词音量 |
| 播报前提示音 | 开 | 念台词前先响两声轻提示，更像系统播报 |
| 开口前留白 | 240 ms | 提示音响过之后停多久再开口，0 – 1200 ms |

### 界面音效

| 选项 | 默认 | 作用 |
|---|---|---|
| 界面音效 | 开 | 文字出现、阶段推进、按钮确认的「哒」声 |
| 音效音量 | 0.5 | 界面音效音量（不影响台词） |
| 音效来源 | 内置素材 | `内置素材` 用录音 / `现场合成` 用代码合成 |

### 视觉

| 选项 | 默认 | 作用 |
|---|---|---|
| 强调色 | `#ff9a1f` | 阶段条、进度条、准星的军用琥珀 |
| 故障色 A / B | `#ff3b30` / `#2971b8` | 揭幕那下色散故障的红与蓝 |

### 文案

| 选项 | 默认 | 作用 |
|---|---|---|
| 品牌三行 | `MILITIA` / `FREE FRONTIER` / `SRS MK.7` | 左上角番号块 |
| 黑幕三行 | `自由边境` / `MILITIA` / `VANGUARD CLASS · TITAN OS` | 开场黑幕上的字 |
| 终幕方框 | `BT-7274` | 揭幕后中央的黑底白字框 |
| 页脚 | `POWERED BY TITAN OS` | 右下角页脚 |
